# 💻 NIRD OS : L'expérience NIRD en avant-première !

**NIRD OS** est un **Webtop (Web + Desktop)** conçu lors de la **Nuit de l'Info 2025** par l'équipe des Infomnies. Son objectif est de transmettre les solutions proposées par la démarche NIRD via une interface Web identique à une distribution Linux minimale.

## 🎯 Défis relevés
1. **Decathlon** : quiz dynamique pour recommander les meilleurs produits selon votre profil.
2. **VIVERIS** : un chatbot volontairement idiot… mais toujours prêt à répondre.
3. Style rétro inspiré des années 90, activable via les paramètres. Merci **IUT du Littoral Côte d’Opale**.
4. Optimisation automatique du **NIRD OS** pour machines reconditionnées. Défi de l’**EPITECH Bordeaux**.
5. Un Snake caché dans les fichiers root. Défi **AUTOCUT**.

---

## 🛠️ Stack technique
- **Frontend :** HTML5, CSS3, JavaScript
- **Backend :** PHP 8, Python
- **Base de données :** PostgreSQL
